# Contributing

Репозиторий принимает только изменения, не содержащие персональные данные и закрытые артефакты проекта.

Перед commit:

```powershell
python scripts/check_public_repo.py
python -m pytest -q
ruff check .
```

Запрещены фотографии и их миниатюры, EXIF, реальные названия учреждений и файлов, абсолютные пути к архиву, manifests, checkpoints, веса, archives и результаты экспериментов. Для тестов изображения генерируются во временном каталоге во время запуска.
