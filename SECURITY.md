# Security policy

Не публикуйте здесь фотографии, кропы лиц, реальные пути, манифесты, веса, checkpoints или архивы. Полная политика и порядок реакции на утечку описаны в [docs/SECURITY.md](docs/SECURITY.md).

Для сообщения об ошибке используйте синтетический пример без персональных данных. Не прикладывайте реальные школьные фотографии к публичному issue.
